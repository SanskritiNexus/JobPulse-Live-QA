Live External Job API Architecture

This application integrates with official external job-data APIs. API keys are stored strictly in backend server environment variables (.env) and are never exposed in frontend code.

🔑 How to Add Free Adzuna Credentials:

  1. Sign up for a free developer account at developer.adzuna.com.
  2. Copy your app_id and app_key.
  3. Open .env file in project directory and paste your values: 
    ADZUNA_APP_ID=your_app_id_here
ADZUNA_APP_KEY=your_app_key_here
JOB_API_PROVIDER=adzuna
  4. The backend will automatically start fetching live real-time job listings directly from Adzuna's India search engine!
